# Portfolio Website - Django Project

## Overview
This is a **personal portfolio website** built using **Django**. It is designed to showcase a professional online presence and highlight your skills, projects, and contact information. The website is fully responsive and styled with **Tailwind CSS**, providing a clean and modern user interface.

The contact form allows visitors to send messages that are stored in the **Django Admin Panel**, making it easy to manage and respond to inquiries.

---

## Features

- **Hero Section:** Eye-catching landing area with name, title, and call-to-action.  
- **About Me:** Personal introduction including background, experience, and education.  
- **Skills:** Display of technical skills and tools with visual indicators.  
- **Projects:** Portfolio section showcasing projects with descriptions, technologies used, and links to live demos or GitHub repositories.  
- **Contact Form:** Visitors can submit messages that are saved to the database and visible in the Django Admin Panel.  

---

## Deployment

The project is deployed on **PythonAnywhere**, making it accessible online with a professional URL. It is fully tested for responsiveness across devices and optimized for performance.

---

## Technology Stack

- **Backend:** Django (Python)  
- **Frontend:** Tailwind CSS, HTML5, CSS3  
- **Database:** SQLite (default for development; can be switched to MySQL/PostgreSQL)  
- **Deployment:** PythonAnywhere  

---

## Project Structure

The project is structured to follow Django best practices:

- **Apps for modular features** like home, projects, and contact.  
- **Templates** for reusable HTML pages.  
- **Static files** for CSS, JS, and images.  

This structure ensures easy maintenance, scalability, and code readability.
